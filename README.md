A tiny Node program that writes one short text to `/output/entry.txt` — a single-line joke about cats. The cat knocked the laptop off the desk, sat in its warm spot, and looked at the human like the human was the one who didn't belong there. A scene you can see in one read, with the reversal as the punchline. 120 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
